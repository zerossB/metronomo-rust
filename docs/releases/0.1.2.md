# Metronomo 0.1.2

This release updates Linux packaging and release automation. It includes the
metronome controls, saved preferences, and named presets from 0.1.0.

## Changes

- AppStream metadata supplies the developer, MIT license, release date, project
  links, screenshots, and English/Brazilian Portuguese descriptions.
- The desktop launcher and scalable/64/128/256-pixel icons use the same
  application identity.
- `dirs` is updated to version 7.
- CI reuses compilation caches and validates metadata, installation,
  reinstallation, removal, and preference retention.
- Cargo, Debian, and tagged release versions are aligned. The immutable
  `v0.1.1` release could not produce installers because its source still
  declared version `0.1.0`; it has been preserved, and this version replaces it
  for downloads.

## Installation

Targets are Ubuntu **24.04 and 26.04 amd64**, a graphical X11 or Wayland session,
a working default audio output, and a Vulkan-capable driver.

```sh
sha256sum --check SHA256SUMS
sudo apt install ./metronomo_0.1.2-1_amd64.deb
metronomo
```

The application appears as **Metronomo** in the desktop application menu.
Removing or reinstalling it preserves personal settings in
`~/.config/metronomo/settings.json` (or `$XDG_CONFIG_HOME/metronomo/settings.json`).

## Validation and limitations

Automated checks cover Rust/Python tests, compilation, Clippy, offline audio
timing, desktop/AppStream metadata, and clean Ubuntu installation. Physical
audio timing and the full desktop matrix remain documented in the bundled
validation report; this packaging update does not supply new measurements.

A local `.deb` is unrestricted and can show a third-party-source warning.
Ubuntu App Center's local-file reader may leave fields unknown despite complete
bundled metadata. Other distributions, architectures, and automatic updates
remain outside the validated support scope.

The project is MIT licensed. Bundled dependencies retain their own licenses in
`/usr/share/doc/metronomo/third-party-notices.txt`.
