# Metronomo 0.1.0

**Release candidate — not approved for publication.** See the accompanying
`manifest.json` and validation report for outstanding acceptance checks.

Metronomo provides a focused desktop practice tool: synthesized metronome clicks,
40–240 BPM, configurable meters, independent beat sounds, Tap Tempo, keyboard
operation, saved preferences, and named presets.

## Installation

The intended targets are Ubuntu **24.04 and 26.04 amd64**, with X11 or Wayland,
a working default audio output, and a Vulkan-capable graphics driver. These are
validation targets; the validation report records which configurations have
actually passed. Other distributions and architectures are unvalidated.

```sh
sha256sum --check SHA256SUMS
sudo apt install ./metronomo_0.1.0-1_amd64.deb
metronomo
```

The application is also available as **Metronomo** in the desktop application
menu. Rust and development headers are unnecessary on the installed system.

```sh
sudo apt remove metronomo
```

Removing or reinstalling the package leaves personal settings in
`~/.config/metronomo/settings.json` (or `$XDG_CONFIG_HOME/metronomo/settings.json`).
The package contains no personal settings and does not play audio on installation.

## Limitations

- Playback uses the default device; Start retries after an output failure.
- Backend timestamps predict output timing. Physical audio and rendered visual
  alignment require separate loopback/video validation.
- Bluetooth latency, remote desktops, macOS, Windows, ARM64, stores, and automatic
  updates are outside this release's validated support scope.
